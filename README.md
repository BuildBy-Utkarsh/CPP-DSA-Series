## 📖 About This Challenge

Welcome to my **90-Day Data Structures & Algorithms Challenge** — a personal commitment to sharpen my problem-solving skills and build a rock-solid DSA foundation in **C++**, one day at a time.

This repository is both a **learning journal** and a **code archive**. Every day I solve at least one problem, write clean commented code, and log my progress — the wins, the struggles, and the lessons learned.

**Why 90 days?**
It's long enough to build real depth, short enough to stay urgent. No shortcuts, no skipped days (unless life truly demands it) — just steady, visible progress.

---

## 🎯 Goals

- ✅ Master core data structures: Arrays, Strings, Linked Lists, Stacks, Queues, Trees, Graphs, Heaps, Tries, Hash Maps
- ✅ Build strong intuition for algorithmic paradigms: Recursion, Backtracking, DP, Greedy, Divide & Conquer
- ✅ Solve 150+ problems across difficulty levels
- ✅ Improve time & space complexity analysis skills
- ✅ Get interview-ready for SDE roles
- ✅ Build a public, trackable record of daily consistency

## 🔥 Daily Habit Rules

1. Solve **at least 1 problem** every day — no zero days.
2. Write the code **myself first**, before checking editorial solutions.
3. Add a short note on approach + time/space complexity.
4. Commit and push **every single day** to keep the streak alive.
5. Revise weekly — Sundays are for revisiting tricky problems.
